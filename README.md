# ⚡ ThinkAI Studio — Your Personal AI Assistant

A complete, production-grade AI Chatbot web application built for college technical presentations and live judge demonstrations on **Large Language Models (LLMs)**, **Agentic AI**, and **Big Data**.

Powered by the official **Google Gen AI Python SDK (`google-genai`)** and **Streamlit**, featuring real-time token streaming, stateful multi-turn memory, customizable system personas, and tabular dataset intelligence.

---

## 🌟 Key Features

1. **Live Gemini Model Inference**: Real-time generation powered by Google's cutting-edge Gemini models (e.g., `gemini-3.5-flash-lite`, `gemma-4-31b-it`, `gemini-3.8-flash`). No fake chatbots, predefined mock data, or local approximations.
2. **Real-Time Token Streaming**: Text chunks stream progressively into the UI as generated by the model.
3. **Multi-Turn Stateful Memory**: The assistant preserves conversational context across turns using the official `chats.create` abstraction.
4. **Interactive Tech-Talk Quick Prompts**: Instant one-click demonstration buttons for:
   - What is an LLM?
   - LLMs vs. Agentic AI
   - The 3 Vs of Big Data
   - Self-Attention in Transformers
   - AI Analysis of Tabular / CSV Datasets
5. **Big Data CSV Inspector**: Upload any CSV or load the bundled enterprise tech dataset to generate instant AI business intelligence and statistical summaries.
6. **Configurable Controls**:
   - Model switcher with verified models.
   - Temperature slider ($0.0$ to $2.0$) for deterministic vs. creative output.
   - System persona editor (Tech-Talk Presenter, Software Architect, Big Data Scientist, Concise Analyst).
7. **Production Security & Error Sanitization**: Credentials are read from environment variables (`GEMINI_API_KEY` or `GOOGLE_APPLICATION_CREDENTIALS`) and safely masked (`API_KEY...XXXX`). Exceptions (such as quota exhaustion or temporary server spikes) are translated into clear, actionable advice without ever exposing credentials.

### 🎓 Important Concepts for Judges & Tech-Talks

| Concept | What It Is | Role in Modern AI Systems | Real-World Analogy |
| :--- | :--- | :--- | :--- |
| **Large Language Model (LLM)** | Deep neural network (Transformer) trained on vast textual datasets. | Understands semantic context, writes code, translates languages, and predicts next tokens. | **The Brain**: Knows information and communicates fluently. |
| **Agentic AI** | Autonomous framework combining an LLM with memory, planning, and external tools. | Executes real-world tasks, runs Python code, writes SQL queries, calls REST APIs, and self-corrects. | **The Hands & Feet**: Takes deliberate real-world actions. |
| **Big Data** | Massive data characterized by the 3 Vs: **Volume**, **Velocity**, and **Variety**. | Stored in Data Lakes / Warehouses (BigQuery, Spark) to feed vector embeddings and fine-tuning pipelines. | **The Ocean**: The fuel that trains and grounds AI models. |

## 🚀 Quick Start (Fedora Linux / Ubuntu / macOS)

### 1. Prerequisites
- Python **3.11** or compatible (`python3 --version`)
- A valid Google Gemini API Key

### 2. Setup Virtual Environment

```bash
# Clone or navigate to the project directory
cd /home/harivikram/LLM

# Create virtual environment
python3 -m venv .venv

# Activate virtual environment
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Your API Key

Create your local `.env` file from the provided template:

```bash
cp .env.example .env
```

Edit `.env` and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

*(Note: `.env` is included in `.gitignore` to prevent committing secrets to source control).*

### 5. Launch the Web Application

```bash
streamlit run app.py
```

The web application will open automatically in your browser at `http://localhost:8501`.

## ⏱️ 2-Minute Live Tech-Talk Demonstration Script for Judges

When presenting to judges, follow this concise 4-step sequence:

### Step 1: Interface & API Connection (30 Seconds)
1. Open the **ThinkAI Studio** dashboard.
2. Direct the judges' attention to the **Sidebar**:
   - Point out the **API Connection Status** badge showing `🟢 Connected`.
   - Highlight that the API key is safely masked (`API_KEY...XXXX`) following enterprise security practices.
   - Point out the active model: `Gemini 3.5 Flash-Lite` (or `Gemma 4 31B IT`).

### Step 2: Live LLM Streaming & Demonstration Prompts (45 Seconds)
1. Click the **"🤖 LLM vs Agentic AI"** demo chip.
2. Show the judges the **real-time token streaming** in action.
3. Highlight the structured response explaining how an LLM acts as the reasoning engine while an Agent adds tool calling (APIs, code interpreters) and autonomy.

### Step 3: Multi-Turn Memory & Persona Customization (30 Seconds)
1. In the chat input, type: *"How does this relate to the concept of self-attention we discussed earlier?"*
2. Demonstrate that ThinkAI remembers preceding messages in the multi-turn session.
3. In the sidebar, tweak the **Temperature** slider (e.g., lower to $0.2$ for deterministic technical answers) or switch the **Persona** to *"Big Data & AI Scientist"*.

### Step 4: Big Data Dataset Inspector (15 Seconds)
1. Switch to the **"📊 Big Data & Dataset Inspector"** tab.
2. Click **"📁 Load Sample Tech-Company Dataset"** to display tabular telemetry.
3. Click **"🚀 Analyze Dataset with ThinkAI"** to demonstrate how modern LLMs ingest tabular schemas and generate automated statistical business intelligence.

## 🛠️ Troubleshooting

- **503 UNAVAILABLE (High Demand)**: During peak times, certain preview models like `gemini-3.8-flash` may experience temporary spikes. Simply select `gemini-3.5-flash-lite` or `gemma-4-31b-it` from the sidebar dropdown.
- **429 RESOURCE_EXHAUSTED (Quota Exceeded)**: You have exceeded the rate limit for the current minute. Pause for 10-15 seconds before submitting another prompt.
- **Key Missing**: Ensure `.env` is located in the working directory where `streamlit run app.py` is invoked, or paste the key into the sidebar text field.
